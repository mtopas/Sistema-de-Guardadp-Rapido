## CONTEXTO DEL PROYECTO

Estás diseñando el sistema visual completo de una aplicación personal full-stack
llamada **Sistema de Guardado Rápido (SGR)**. Es una web app + bot de Telegram,
pensada para uso personal en PC y mobile, corriendo en un HomeLab propio.

La app está dividida en **cuatro módulos** que comparten el mismo diseño:

  1. Bóveda     — captura de conocimiento (base ya construida)
  2. Hábitos    — tracker de hábitos con grilla mensual
  3. Agenda     — calendario con repeticiones y calendarios múltiples
  4. Finanzas   — gestión de flujos, patrimonio y proyección FIRE

**Stack técnico (no cambies nada de esto):**
- Frontend: React + Vite + Tailwind CSS + Zustand
- Temas: CSS variables en `document.documentElement` (`--bg`, `--surface`,
  `--sidebar`, `--accent`, `--accent-light`, `--text`, `--subtext`, `--border`,
  `--panel-bg`)
- Fuentes actuales: Sora (body), Playfair Display (logo/marca)
- Iconos: Lucide React
- Animaciones: CSS + keyframes, 100–200ms, sin librerías externas
- El diseño debe seguir siendo 100% compatible con el sistema de temas existente

## DISEÑO VISUAL BASE (herencia del módulo Bóveda ya construido)

El diseño actual tiene estas características que DEBEN mantenerse en todos los
módulos nuevos:

**Estética general:**
- Dark-mode dominante (7 de 8 temas son oscuros)
- Bordes redondeados: rounded-xl (0.75rem) estándar, rounded-2xl para inputs
- Superficies semitransparentes con backdrop-filter: blur() en paneles flotantes
- Glow effects: box-shadow con el color del acento al 30-55% de opacidad
- Gradientes de texto: linear-gradient 130deg de --accent a --accent-light con
  background-clip: text
- Scrollbars custom: 4–5px, thumb en gradiente accent→accent-light

**Tipografía:**
- Logo/marca: Playfair Display, serif, font-bold
- Todo lo demás: Sora, sans-serif
- Jerarquía: text-xl (logo), text-lg (sección headers), text-sm (body),
  text-xs (meta/etiquetas)
- Etiquetas de sección: text-[10px] uppercase tracking-widest font-semibold

**Estados interactivos:**
- Hover: cambio de color + fondo ligero
- Active: scale-95 o scale-[0.99]
- Focus: border-color → --accent
- Seleccionado (nav activa): fondo degradado + borde izquierdo en --accent

**Animaciones:**
- slideUp: 0.15s ease-out, opacity 0→1 + translateY 8px→0
- fadeIn: 0.15s ease-out
- El FAB rota su ícono Plus 45° cuando está en modo captura

**Layout desktop:**
- Estructura de 3 paneles: LeftPanel fijo (280px) + centro (flex-1) + RightPanel
  (320px) flotante sobre el grafo en Bóveda
- TopBar horizontal con logo + búsqueda centrada + avatar dropdown
- Sidebar de 224px en rutas secundarias (Capture, Detail, Settings)

**Layout mobile:**
- Bottom navigation fija (4 tabs: módulos principales)
- FAB flotante en el centro del bottom nav (w-14 h-14 rounded-full con glow)
- Sin sidebar, sin TopBar lateral

**Colores por rama del grafo (Bóveda, invariantes entre temas):**
#8b5cf6, #06b6d4, #10b981, #f59e0b, #ef4444, #3b82f6, #f97316, #14b8a6,
#a855f7, #f43f5e

### 2.1 HabitsScreen — Vista Principal Desktop

**Layout:**
```
TopBar (igual al de Bóveda)

LeftPanel (280px fijo)  │  Centro (flex-1)
  - Header "Mis Hábitos"│  HabitGrid (grilla mensual)

    con chips de color   │

─────────────────────────────────────────────────────────────────────
```

**LeftPanel — Lista de Hábitos:**
- Cada hábito: pill/chip con su color asignado + nombre + indicador de racha
  (streak) como número con ícono de fuego (🔥 o ícono Flame de Lucide) solo si
  racha ≥ 3 días
- Estado del hábito hoy: dot verde (hecho), dot amarillo (pendiente), dot gris
  (no toca hoy)
- Hover: background --surface + borde izquierdo en el color del hábito
- Seleccionado: mismo estilo hover pero permanente + highlight en la grilla

**HabitGrid — Grilla mensual:**
- Encabezado: nombre del mes + año centrado, flechas izquierda/derecha para
  navegar meses, botón "Hoy" que vuelve al mes actual
- Sub-encabezado: fila de números de día (1–31), cada número alineado a su
  columna. Los días del fin de semana en --subtext. El día actual: círculo
  background accent, texto blanco
- Filas de hábitos:
  - Primera columna (sticky left 0, ancho 160px): nombre del hábito con su
    chip de color
  - Columnas de días: celda de 36x36px con:
    * Día activo + no marcado: checkbox custom (border --border, hover border
      accent, 18px, rounded-md)
    * Día activo + marcado: checkbox filled con gradiente accent, checkmark
      blanco, scale-in animation 150ms
    * Día no activo: sin checkbox, fondo ligeramente diferente (--surface a 40%
      opacity)
    * Día futuro: checkbox deshabilitado con opacity 0.3
    * Día actual: columna entera con fondo muy sutil (--accent al 8%)
  - Última columna (sticky right 0, ancho 80px): porcentaje de cumplimiento
    del mes como badge (≥80% verde, 50-79% amarillo, <50% rojo suave)

**ProgressSummary — Barra de progreso diario:**
Sticky en la parte superior del área central, debajo del encabezado del mes.
- "Hoy: X de Y hábitos completados" con barra de progreso animada (ancho
  transición 300ms ease-out), color gradiente de accent
- Si todos completados: barra verde + mensaje de celebración fadeIn

**FooterStats — Comparativa con mes anterior:**
Al pie de la grilla, una row con:
- "Este mes: X% promedio" vs "Mes anterior: Y%"
- Diferencia con flecha up/down coloreada (verde/rojo)
- Mini sparkline SVG de los últimos 6 meses (línea simple, puntos en accent)

Bottom sheet en mobile, modal centrado en desktop (max-w-md, rounded-2xl,
